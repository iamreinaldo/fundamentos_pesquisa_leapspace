# Fundamentos de Pesquisa com LeapSpace

Repositório desenvolvido para ser utilizado como material de apoio para o **seminário sobre a plataforma LeapSpace**, realizado na **Universidade Federal da Bahia (UFBA) - 2026**.

O objetivo é **apresentar e explicar o funcionamento da ferramenta LeapSpace**, demonstrando como ela pode auxiliar pesquisadores durante todo o processo da pesquisa científica.

## 📌 Conteúdo do repositório

Neste repositório serão disponibilizados:

- 📚 **Guia da plataforma:** passo a passo com as principais funcionalidades do LeapSpace e orientações para sua utilização.
- 🧪 **Atividade interativa:** passo a passo da atividade prática para que possam praticar e aprender a utilizar a plataforma.
- 🔗 **Materiais de apoio:** links e recursos utilizados durante o seminário.

## 🎯 Proposta

A proposta é combinar uma breve apresentação teórica com uma **experiência prática**, permitindo que os participantes conheçam o LeapSpace e compreendam como a ferramenta pode ser utilizada como apoio à pesquisa científica.
