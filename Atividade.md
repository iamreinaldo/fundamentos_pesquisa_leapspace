# Atividade prática — Revisão de artigo no LeapSpace

## 1. Criar uma conta no LeapSpace

Acesse: [https://leapspace.org](https://leapspace.org)

- Clique em **Sign Up / Criar conta**
- Faça seu cadastro
- Entre na plataforma

## 2. Iniciar novo chat

- A página iniciar já apresenta um chat novo 

## 3. Definir o tema da revisão

- Utilize o tema proposto durante a atividade
- Defina uma **pergunta ou objetivo** para orientar a busca

## 4. Realizar a busca

- Insira os termos relacionados ao tema
- Execute a busca no **LeapSpace**

## 5. Selecionar um artigo

- Escolha **1 artigo** relacionado ao tema

## 6. Apresentar o resultado

Apresente brevemente com um documento:

- Qual artigo foi escolhido?
- Qual é o objetivo do artigo?
- Quais são os principais resultados?
- Por que ele é relevante para a revisão?
